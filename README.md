# Student Management System — JSON Storage

## 📌 Description
A beginner-friendly student management system using Python and JSON for persistent storage.

## ⚙️ Features
- Add student
- View all students
- Search student by name
- Delete student
- Update student age
- Data saved to JSON file automatically

## 🛠️ Tech Used
- Python
- JSON file handling

## ▶️ Run
```
python main.py
```
